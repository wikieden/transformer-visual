讲解

用一串数字描述一个东西

先不想数学，想想平时怎么描述水果。如果只关心三件事：有多甜、有多大、有多红（各 0–10 分）：

水果 甜 大 红 写成一串数字
苹果 7 5 8 [7, 5, 8]
西瓜 8 10 6 [8, 10, 6]
柠檬 1 3 0 [1, 3, 0]

最后一列这种用方括号括起来的一串数字，就叫向量。

两点要记住：

  1. 每个位置有固定的含义。 第 1 个数永远是"甜"，第 2 个永远是"大"，第 3 个永远是"红"。[7, 5, 8] 和 [8, 5, 7] 描述的是两个不同的东西。
  2. 有几个数，就叫几"维"。 上面每个水果都是 3 维向量。

和 Transformer 的关系

模型不认识文字，只认识数字，所以它把每个词都变成一个向量。区别是：

  • 水果向量只有 3 个数，论文里每个词有 512 个数（论文记作 \(d_{model}=512\)）；
  • 每个位置代表什么，不是人规定的，是模型在训练中自己学出来的。

公式

\[\mathbf a = [a_1, a_2, \dots, a_d]\]
  • 粗体 \(\mathbf a\)：整个向量
  • \(a_i\)（右下角的小字叫下标）：第 i 个数
  • \(d\)：维数，也就是一共有几个数

例：香蕉 [8, 3, 0]，\(a_1=8\)（甜），\(a_2=3\)（大），\(a_3=0\)（红），\(d=3\)。

数学原理

  • 向量空间 \(\mathbb{R}^d\)：所有"d 个实数排成一串"的集合。d 就是维度，第 i 个数叫第 i 个分量。
  • 向量的长度（范数 norm）：所有分量的平方加起来再开根号。后面的点积、余弦相似度、LayerNorm 都会用到。
  • embedding = 查表：词表里有 V 个词，就有一张 V 行 d 列的表 E，第 i 个词的向量就是 E 的第 i 行。数学上等于"one-hot 向量乘矩阵 E"。

公式清单

公式 意思
\(\mathbf x = [x_1, x_2, \dots, x_d] \in \mathbb{R}^d\) 一个 d 维向量
\(\lVert \mathbf x \rVert = \sqrt{\sum_{i=1}^{d} x_i^2}\) 向量的长度
\(\mathbf x_{\text{词}} = E[i]\)，\(E \in \mathbb{R}^{V \times d}\) embedding：取表的第 i 行

PyTorch 对照：把本章的数字用代码算一遍

PyTorch（Py = Python，torch = 火炬：最常用的深度学习框架）。从这一章起，每章附录都有这一节：把讲义里那组数字用代码算一遍，测试负责核对和讲义一致。代码在仓库本地 transformer-deep-dive/solutions/chapter-code/ch01_vector.py，配套测试 tests/test_ch01_04.py（在线版不带代码文件，下面摘了关键几行）。Mac 上直接能跑，不需要 GPU；uv 是 Python 的项目和依赖管理工具，uv run 会自动装好 PyTorch：

讲义 ↔ 代码：

讲义 公式 / 说法 PyTorch 写法 跑出来
向量 \(\mathbf a = [a_1, \dots, a_d]\) torch.tensor([7.0, 5.0, 8.0]) 苹果 [7, 5, 8]
维数 d apple.shape (3,)：3 维
第 i 个数 \(a_i\) apple[i - 1] \(a_1\) = apple[0] = 7
顺序不同就是两个东西 [7, 5, 8] ≠ [8, 5, 7] torch.equal(a, b) False
论文一个词 \(d_{model}=512\) torch.randn(512).view(32, 16) (512,)，画成 32 × 16 的格子

关键几行：

apple = torch.tensor([7.0, 5.0, 8.0])           # 一个向量；PyTorch 里叫 tensor（张量）
apple.shape                                     # torch.Size([3])：3 维
apple[0]                                        # 讲义的 a_1：代码从 0 开始数
table = torch.stack([apple, melon, lemon])      # 3 个水果摞成一张 3 × 3 的表

代码里才看得到的：

  1. 下标从 0 数：讲义的 \(a_1\) 是代码的 a[0]，\(a_d\) 是 a[d - 1]（也可以写 a[-1]，倒数第 1 个）。以后公式和代码对照时，这一位的差别最容易出错。
  2. tensor（张量）：PyTorch 里所有数据都是 tensor。一串数是 1 维（shape 只有一个数），一张表是 2 维（shape 有两个数，行数和列数）；后面的 Q、K、V 都是 2 维 tensor。
  3. 写 7.0 不写 7：带小数点才是浮点数（float32：32 位小数，模型里的数都是这种）。写成整数 7 得到的是整数 tensor，做 softmax 这类运算会直接报错。
