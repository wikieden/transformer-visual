A0 · 读 attention 之前的四个基础概念

来源：对话讲解（2026-10-25），配合 A2-attention-is-all-you-need.md 使用。 一句话：attention = 词变向量 → 点积打分 → softmax 分比例 → 按比例取信息。

速记口诀

概念 口诀
向量 一串数字描一物，位置含义不能乱
点积 对位相乘再相加，数字越大越像它
softmax 分数变比例，加起来等于一
区分 softmax 分注意，LayerNorm 稳数值

符号约定

写法 读法 意思
\(\mathbf a\)（粗体） 向量 a 一整串数字
\(a_i\)（右下角小字） a 下标 i 向量 a 的第 i 个数
\(d\) 维数 一个向量里有几个数
\(\sum_{i=1}^{d}\) 求和，i 从 1 到 d 把 i = 1, 2, …, d 的每一项都加起来

1 向量 vector

\[\mathbf a = [a_1, a_2, \dots, a_d]\]
  • \(a_1\) 是第 1 个数，\(a_2\) 是第 2 个数……一共 \(d\) 个。
  • 每个位置的含义固定。

例：用 [甜, 大, 红] 描述水果，\(d=3\)。

水果 向量 第 1 个数
苹果 \([7, 5, 8]\) \(a_1=7\)（甜度）
香蕉 \([8, 3, 0]\) \(a_1=8\)
柠檬 \([1, 3, 0]\) \(a_1=1\)

论文里每个词是 \(d_{model}=512\) 维向量，每个位置的含义由模型自己学出来。

2 点积 dot product

\[\mathbf a\cdot\mathbf b = a_1b_1 + a_2b_2 + \dots + a_db_d = \sum_{i=1}^{d} a_ib_i\]
  • 中间那串是"展开写法"，最右边是"简写"，两者完全一样。
  • \(\sum_{i=1}^{d} a_ib_i\) 读作：把 i 从 1 到 d，每个位置的 \(a_i \times b_i\) 都加起来。

例：香蕉 · 柠檬 \(= 8\times1 + 3\times3 + 0\times0 = 17\)

例：苹果 · 西瓜 \(= 7\times8 + 5\times10 + 8\times6 = 154\)；苹果 · 柠檬 \(= 22\)。154 > 22，所以苹果更像西瓜。

在 attention 里：拿"她"的向量和句子里每个词的向量各做一次点积，得到每个词的分数 \(s_1, s_2, \dots\)

3 softmax：分数变比例

3.1 朴素版：除以总分（先理解这个）

\[p_j = \frac{s_j}{\sum_{k} s_k}\]
  • \(s_j\)：第 j 个词的分数
  • \(\sum_k s_k\)：所有分数的总和
  • \(p_j\)：第 j 个词分到的比例；所有 \(p_j\) 加起来等于 1

例："她"对 [小明, 苹果, 小红] 的分数 \(s=[2, 1, 5]\)，总分 8：

\[p = [2/8,\ 1/8,\ 5/8] = [0.25,\ 0.125,\ 0.625],\qquad 0.25+0.125+0.625=1\]

3.2 真正的 softmax：先套一个 \(e^{x}\)，再除以总和

\[p_j = \frac{e^{s_j}}{\sum_{k} e^{s_k}}\]
  • \(e \approx 2.718\) 是一个固定的数；\(e^{x}\) 就是"e 的 x 次方"。

补：次方（幂）是什么 - \(2^3\) 读作"2 的 3 次方"，意思是 3 个 2 相乘：\(2\times2\times2=8\)。右上角的小数字 = 自己乘自己几次。 - 往下数的规律（每往下一行就除以 2）：

写法 \(2^3\) \(2^2\) \(2^1\) \(2^0\) \(2^{-1}\) \(2^{-2}\)
值 8 4 2 1 1/2 1/4

所以：任何数的 0 次方 = 1；负数次方 = 1 除以对应的正数次方，永远是正的小数。 - \(e\) 和 \(\pi\approx3.14\) 一样，是数学里一个固定的特殊数，约 2.718。\(e^{x}\) 就是把 2.718 套进上面的规则；x 是小数时用计算器或 Python math.exp(x) 算。 - 和朴素版唯一的区别：每个分数先变成 \(e^{\text{分数}}\)，再除以总和。 - \(e^{x}\) 的性质：x 为正、0、负时 \(e^{x}\) 永远是正数；x 越大 \(e^{x}\) 越大。

x 2 1 0 −1 −2
\(e^{x}\) 7.389 2.718 1 0.368 0.135

为什么要多这一步 · 原因 1：分数可能是负数。 点积可以算出负数。分数 \([2, -1, 5]\) 用朴素版：总分 6，苹果 \(=-1/6\approx-0.167\)，比例是负的，没有意义（注意力不可能"负分配"）。先套 \(e^{x}\) 就都变成正数了：

词 分数 \(s\) \(e^{s}\) 比例 \(e^{s}/156.17\)
小明 2 7.389 0.047
苹果 −1 0.368 0.002
小红 5 148.413 0.950
合计 156.170 1

（附带：朴素版在分数总和为 0 时还会除以 0，\(e^{x}\) 版本不会。）

原因 2：拉开差距，让注意力更集中。 分数每多 1，\(e^{x}\) 就多乘一次 2.718。小红 5 分、小明 2 分：原始只差 2.5 倍，套上 \(e^{x}\) 后 \(e^5/e^2=e^3\approx20\) 倍。同一组分数 [2, 1, 5]：

词 朴素版 softmax
小明 0.25 0.047
苹果 0.125 0.017
小红 0.625 0.936

代入第 4 步（信息向量同 §4）：朴素版得到 [6.25, 8.75]；softmax 得到 \([0.936\times10,\ 0.047\times10+0.936\times10]=[9.36,\ 9.83]\)，几乎就是小红的 [10, 10]。有用的信息被放大，无关的（苹果）几乎不混进来。

3.3 放大过头：softmax 饱和（saturation）

分数差距太大时（如 [2, 1, 50]），softmax ≈ [0, 0, 1]，只看一个词。问题出在学习：模型靠"微调分数 → 看结果变没变"来学。

把小红的分数调高 1 小红比例变化
[2, 1, 5] → [2, 1, 6] 0.936 → 0.976，看得出
[2, 1, 50] → [2, 1, 51] 1.000 → 1.000，没变

比例已经顶到 100%，再调分数结果不变，模型得不到"该往哪调"的信号，学不动（类比：音量旋钮拧到最大，再拧也听不出区别）。

注意：饱和 ≠ 过拟合。饱和是"学不动"；过拟合是"学过头，只会背训练题"。解决饱和的办法见之后讲的 \(\sqrt{d_k}\)。

4 按比例取信息：加权平均 weighted average

\[\mathbf o = p_1\mathbf v_1 + p_2\mathbf v_2 + \dots + p_n\mathbf v_n = \sum_{j=1}^{n} p_j\,\mathbf v_j\]
  • \(\mathbf v_j\)：第 j 个词携带的信息向量（value）
  • \(p_j\)：第 j 个词分到的比例（上一步算的）
  • \(\mathbf o\)：最终得到的新向量（output），是"她"读完整句之后的理解
  • 一个数 × 一个向量 = 向量的每个位置都乘这个数：\(0.625\times[10,10]=[6.25, 6.25]\)

生活里的同款：总评 = 平时 × 0.3 + 期末 × 0.7。

例：信息向量 [像女生的程度, 是人的程度]

词 \(\mathbf v_j\) \(p_j\)
小明 \([0, 10]\) 0.25
苹果 \([0, 0]\) 0.125
小红 \([10, 10]\) 0.625
  • 第 1 个位置：\(0.25\times0 + 0.125\times0 + 0.625\times10 = 6.25\)
  • 第 2 个位置：\(0.25\times10 + 0.125\times0 + 0.625\times10 = 2.5 + 0 + 6.25 = 8.75\)
  • 结果 \(\mathbf o=[6.25,\ 8.75]\)："她"比较像女生，并且很确定是人。信息大部分来自小红，小明也贡献了一点"是人"。

5 为什么除以 \(\sqrt{d_k}\)

  • 根号：\(\sqrt{64}\) = "哪个数自己乘自己等于 64" = 8。平方根是次方反过来：\(8^2=64 \Leftrightarrow \sqrt{64}=8\)。
  • 分数为什么会大：点积是 \(d_k\) 项相加。把每一项想成随机的 +1 / −1（抛硬币），加起来通常离 0 约 \(\sqrt{d_k}\)。论文 \(d_k=64\)，分数通常 ±8 左右。例 [8, −8, 3] → softmax 第一个占 99.3%，接近饱和。
  • 解决：每个分数除以 \(\sqrt{d_k}=8\)，回到 ±1 左右。[8, −8, 3] ÷ 8 = [1, −1, 0.375] → softmax [0.599, 0.081, 0.320]，不再饱和，调分数会有反应。
  • 这就是论文名字里的 "scaled"（缩放）：Scaled Dot-Product Attention = 缩放点积注意力。

6 论文公式 1 就是这几步合起来

\[\text{Attention}(Q,K,V)=\text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V\]
公式里的部分 对应哪一步
\(QK^\top\) 第 2 步：一次性把所有点积都算出来
\(\text{softmax}(\cdot)\) 第 3 步：分数变比例
\(\cdot\,V\) 第 4 步：按比例取信息
\(\sqrt{d_k}\) 打分后先缩小，防止 softmax 饱和（§5）

\(Q\)、\(K\)、\(V\)、矩阵这些还没讲。
