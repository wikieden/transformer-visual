# 从零读懂 Transformer

**在线阅读：<https://wikieden.github.io/transformer-visual/>**

从向量、点积讲起，一步步走到论文《Attention Is All You Need》第 3 节的完整 Transformer。共 24 章，每章配一个动画（GIF + 可交互页面），附复习卡片和缩写表。讲义保留了学习时的练习与作答记录。

- [讲义目录](https://wikieden.github.io/transformer-visual/lessons/index.html)
- [全部动画](https://wikieden.github.io/transformer-visual/animations/index.html)：▶ 播放、→ 单步、↺ 从头开始，有滑块的可以拖动参数
- [复习卡片](https://wikieden.github.io/transformer-visual/review.html)：先自己答，再点开答案

本仓库由私有学习仓库里的脚本 `tools/publish-transformer/build.py` 自动生成，不要直接修改这里的文件。
