第 23 章 · 复杂度：为什么 attention 是 n²，长文本为什么难

配套讲义：第 23 章 · 复杂度：为什么 attention 是 n²，长文本为什么难。n = 句子有几个 token；d = 每个词几个数；RNN = Recurrent Neural Network（循环神经网络）。显存按每个数 2 字节粗算。

63

看点：① 全班两两握手：分数表 n × n 格，每格一次 d 维点积，打分要 n²·d 次乘法；② n 翻倍，格子变 4 倍；③ RNN 传话要排队 n 步，attention 所有格子同时算；④ 第 1 个词到最后一个词：RNN 走 n − 1 步，attention 一步直达；⑤ n < d 时 n²d 比 nd² 小；⑥ n 到十万，一张分数表就要约 20 GB。滑块：n 从 10 拖到 100000，看格子数、和 RNN 的比值、一张分数表的显存。
